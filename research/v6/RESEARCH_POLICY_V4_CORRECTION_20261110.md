# v3 지시문 긴급 정정 — 자동 전략 개발 우선 (2026-11-10)

## 원래 실패 원인
이전 작업은 논문 원문에 정량 매매규칙이 완전히 기재되지 않으면 `RULE_EXTRACTION_INCOMPLETE`로 코드를 생성하지 않았습니다. 이는 **경제적 거래구조를 근거로 새로운 전략을 창안·검증하는 AI 연구 엔진**의 핵심 목적과 충돌합니다. 근거의 허위 귀속을 방지하는 안전장치는 유지하되, 이를 전략 설계 중단 명령으로 사용하지 않습니다.

## 변경된 필수 실행 규약
1. **PAPER/LIVE 차단 ≠ RESEARCH 코드 생성 차단.** 경제적 관계가 문헌·거래소 자료에서 확인되면, 불완전한 매매규칙은 연구자/AI가 `RESEARCH_ASSUMPTIONS`로 보완하여 완결된 매매 로직 및 Python 구현을 반드시 시도합니다.
2. `SOURCE_CONFIRMED_RULES`에는 원문에 실제 있는 경제적 구조·방법·계산식만 기록합니다. `RESEARCH_ASSUMPTIONS`에는 논문에 없는 가격 밴드 배수, RSI 기간, 운용 월물, 거래소 레그 비율, 시차, 청산, 주문 체결, 거래비용, 위험 한도를 기록합니다.
3. 자료가 부족할 때의 순서는 추가 검색 → 실물 계약 명세 조사 → 경제적 원인 기반 수식 설계 → 실행 가능한 구조화 전략 명세 생성 → Python 코드 생성 → 결정론적 합성 데이터 기능시험 → 실데이터 확보·백테스트 계획입니다. 외부 웹 검색이나 계좌 접근이 불가능해도 코드 개발/합성 기능시험을 우선 완수합니다.
4. 기존 분류 87개와 추가 12개는 누락하지 않습니다. 정본 미확보 상태라면 임의 명칭을 만들어 넣지 말고 확보 여부와 분석된 부분을 명시하되 연구 작업 자체는 계속합니다.
5. 자동 발굴 엔진은 1개 원본에서 0~N개 **차별적인 거래구조 후보**를 생성하며, 이미 알려진 사례를 하드코딩한 조회만으로 완료 처리할 수 없습니다.
6. 최소한 세 가지 전략 생성 능력을 갖춥니다: (가) 15일 헤지·스프레드 평균복귀, (나) 원자재 스프레드 RSI 조합, (다) 국제 거래소·통화 Bid/Ask 기반 동시거래 차익 신호. 각 전략마다 레그·매수/매도·승수·시장/시간봉·수식·진입/청산·비용·리스크·테스트·20항목 보고서를 제출합니다.
7. **전략 개발 성공**은 `RESEARCH_STRATEGY_IMPLEMENTED`와 `SYNTHETIC_FUNCTIONAL_PASSED`를 별도 표기합니다. **수익성 검증 성공**은 실데이터·비용·재현성·워크포워드 등 엄격한 별도 검증을 통과했을 때만 표기합니다. 데이터가 없어도 코드 생성 완료를 `RULES_INSUFFICIENT`로 되돌리지 않습니다.
8. 결론은 세 단계로 분리합니다: `RESEARCH_DESIGNED`(AI/연구자 설계), `RESEARCH_CODE_TESTED`(합성 기능시험), `MARKET_VERIFIED`(실시장 데이터/체결비용 검증). 첫 두 단계를 실제 코드로 완성해도 최종 거래 적합성은 별개입니다.
