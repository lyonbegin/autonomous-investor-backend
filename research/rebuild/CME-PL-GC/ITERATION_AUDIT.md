## 구조적으로 복원한 거래
- 교육용 예제이며 실제 거래 체결 증거는 아니다.
- 롱 스프레드, 백금 April 선물 **2계약 × 50 troy oz**, 금 April 선물 **1계약 × 100 troy oz** 매도.
- 3월 2일 진입, 3월 30일 청산; **연도는 원문 미공개**.
- 백금 매수 $988.40/oz → 매도 $1,056.40/oz. 장부가격 98,840→105,640 USD, 매매손익 +6,800 USD.
- 금 매도 $1,231.90/oz → 매수 $1,244.20/oz. 장부가격 123,190→124,420 USD, 매매손익 −1,230 USD.
- PL−GC 스프레드 −243.50 → −187.80 USD/oz, 변동 +55.70 USD/oz.
- 레그 합계 총손익 +5,570 USD.
- 자동차 판매↑ → 촉매용 백금 수요↑ → 백금의 금 대비 상대강세 예상 → 음수 백금−금 스프레드 축소 기대; 이것은 경제적 가설이며 기계적 자동 진입 신호가 아님.
- 청산기관 상계로 스프레드의 증거금이 별도 직접 포지션보다 낮아질 수 있지만 **실제 증거금 액수는 주어지지 않았다**.

## 수치 검산
```
PL = 2 contracts × 50 oz/contract × ($1,056.40 - $988.40)/oz = +$6,800
GC = 1 contract × 100 oz/contract × ($1,231.90 - $1,244.20)/oz = -$1,230
Total gross = +$6,800 + (-$1,230) = +$5,570
Spread entry = $988.40 - $1,231.90 = -$243.50/oz
Spread exit = $1,056.40 - $1,244.20 = -$187.80/oz
```

## 검증의 엄밀한 범위

- `round-3-graph-only-input.json`은 소스 문서·원문 사실등록부·출처 노드 16개를 제거한 그래프 전용 입력이다.
- `round-3-graph-only-reconstruction.json`은 해당 입력의 금융 노드/관계만 따라 다시 구성한 명세다.
- `round-3-source-comparison.json`은 **선정된 15개 원문 핵심 사실에 대해 15/15 일치**를 기록한다.
- 이는 동일 작업 환경의 그래프 경로 재구성이므로 **새로운 독립 ChatGPT 대화를 거친 검증이라고 말하지 않는다.**
- 원문 전체 문장 및 자료 부록을 완전 전수검증한 것도 아니다.
- `active.json`은 `BLIND_PENDING_NOT_FULL_PASS`를 유지한다.

## 온톨로지
기존 노드의 올바른 연결로 해결 가능한 영역을 우선 유지하고, 인과·증거금 비교처럼 독립적 경제 의미가 실제로 필요한 경우만 7개 노드 유형과 관련 관계를 `v9-ontology-proposals.json`에 후보로 남겼다. 원본 604개 출현 이력을 삭제·축소하지 않는다. **실제 정본 승인은 중복 정의 검사와 이전 다섯 사례 회귀시험 이후로 보류한다.**

## 계속 반복할 조건
독립 ChatGPT 블라인드 시험이 실패하면 R3를 비활성화하고, 원문의 해당 사실과 기존 온톨로지를 재확인하여 R4 그래프를 **완전 재생성**한 뒤 다시 시험한다. 현 상태는 종결이 아닌 다음 반복 대기다.
