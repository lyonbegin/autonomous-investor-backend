### 공개 TradingView 설명과 그래프에서 복원 가능한 주요 사실

- 외부 매수·매도 신호의 부호별 해석
- 처음 유효 신호에서 즉시 포지션 개설, 동시에 최대 포지션 1개
- 같은 방향 신호 무시
- 반대 방향 신호에 대한 무시 / 청산 / 청산 후 반전 선택
- 별도 취소 신호의 부호별 청산 대상
- 일반 손절, 초기 트레일링 손절, 트레일링 손절의 구별
- 초기 트레일링 손절의 cutoff 후 가격 고정
- 일반 트레일링 손절의 후속 적용 가능성
- 일반·초기·트레일링 손절의 병행 사용 가능성
- 저자의 'Trailing Stop > Initial Trailing Stop >= Stop' 가이드가 실행의 강제 조건은 아님
- 분할익절 4단계와 각각의 가격 이익 임계값, 포지션 축소량
- 값이 미공개이거나 아직 추출되지 않은 속성의 정확한 노드 위치

**아직 복원 불가:** 개별 전략 사용자가 설정한 취소/반대 신호 처리 기본값, 각 TP 수치 및 축소 단위·수량, Pine 전체 코드를 통한 주문/봉내 처리, 실제 거래의 종목·체결정보. 이 TradingView 원본은 범용 거래관리 전략이며 특정 실제 체결을 증명하지 않습니다.

## 연관 연구 · EURUSD 실험 a,b,c

기존 44노드·88관계 → **54노드·109관계**. 실험별 MACD 파라미터와 주말 포지션 처리 규칙을 별도 노드·관계로 연결했습니다.

| 실험 | MACD fast/slow/signal | 주말 처리 | 원문 보고 순손익 |
|---|---|---|---:|
| a | 12 / 26 / 9 | 주말 전에 포지션 종료 | −$7,229.86 |
| b | 27 / 280 / 28 | 주말 전에 포지션 종료 | +$4,348.97 |

## 앞으로 같은 방법으로 처리

**새 TradingView 원본 한 건 → ChatGPT 1차 추세 전용 여부 판별 → ChatGPT 지정 검색처 직접 검색 → 실제 논문/예제 판별 → 기존 온톨로지로 그래프 구성 → 독립 새 대화에서 그래프만 받아 역재현 → 원문과 비교 → 누락된 노드·속성·관계 추가 → 그래프 재생성 → 재검증**을 원본별 반복합니다.

**연동 제한:** HITEL Web2API 연구 작업 전송·응답 규약은 아직 받지 못했습니다. 현재 GitHub Actions는 연구 지시문 패키지 준비만 가능하며, 새 대화의 독립 ChatGPT 역재현은 자동화되지 않았습니다. 임의로 시스템 API 또는 기존 로그인의 계정 연결을 구현했다고 보고하지 않습니다.
