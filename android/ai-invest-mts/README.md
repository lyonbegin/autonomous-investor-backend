# AI 투자 스튜디오 · 독립 Android APK

검증된 모바일 투자 앱의 화면·함수 입출력 분석을 자료로 사용해 **별도 앱**을 조립한 Android 프로젝트입니다. 원본 토스 금융앱을 변조하거나 재서명한 앱이 아닙니다. 원본 소스·상표·이미지·증권사 비공개 인증과 API는 포함하지 않습니다.

- 화면: 홈, 발견, 종목 상세, 관심종목, AI 상담 전문가 선택·대화 기록, 내 자산, 주문안 입력·확인.
- 로컬 상태: SharedPreferences 관심종목, 입력된 주문안, AI 질문 기록.
- 외부 네트워크 권한 없음. 실시간 시세·거래·실제 AI 서버 연결 없음. 원본 고객계정 입력받지 않음.
- 본 소스는 원본 ARM64 함수 복원품이 아니며, 실행 가능한 독립 MTS UX 원형입니다. 토스 라이브러리는 앱 서명·프로세스·서버·JNI 환경과 결합되어 있어 그대로 가져오면 동작한다는 증거가 없습니다.

빌드: JDK17 + Android SDK35 + Gradle 8.10.2에서 `gradle :app:assembleDebug`. 테스트: GitHub Actions 실제 Android 14 에뮬레이터 실행.
