# n8n 원본 Vue 편집기 사용성 실테스트 — TinyFish 시나리오

대상 URL: https://investment-n8n-native-editor-production.up.railway.app/
대상 브랜치: feature/n8n-native-editable-test-20261028
테스트 조건: 원본 Vue NodeView / WorkflowCanvas / NodeDetailsView를 사용한다.
시뮬레이션 브라우저에만 초안을 저장하고 실제 주문이나 운영 n8n 서버는 건드리지 않는다.

## 합격 기준(각 조작을 실제 사용자 브라우저에서 확인)

1. **접속**: 로그인/기본인증 팝업 없이 접속한다. 좌측 선택지 13개 노출.
2. **캔버스**: F01 또는 합성 시나리오 01 클릭 시 실제 n8n VueFlow 노드와 연결선 노출.
3. **노드 선택 및 설정**: 노드를 더블클릭, 원래 비활성화된 설정 필드에 텍스트/숫자를 입력하고 값 변경을 눈으로 확인한다.
4. **노드 이동**: 노드를 드래그해 원래 위치와 다른 좌표에 놓고 시각적 위치 변화 확인.
5. **노드 추가**: 빈 화면 우클릭 → Add node 또는 '+' 버튼에서 n8n 노드 추가. 새 노드 카드가 표시돼야 한다.
6. **노드 연결**: 출력 포트를 드래그해 새로운 노드의 입력 포트에 선 연결, 엣지 수 증가.
7. **연결선 삭제**: 테스트 중 새로 추가한 선만 삭제한다. 엣지 수 원복.
8. **노드 복제/이름 변경/삭제**: 신규 테스트 노드에 복제와 이름 변경을 수행하고 삭제한다.
9. **실행 취소/다시 실행**: Ctrl+Z와 Ctrl+Shift+Z 또는 UI 사용, 캔버스 변화 확인.
10. **저장**: '변경 저장' 버튼을 눌러 저장 성공 메시지 확인.
11. **새로고침 후 복원**: 새로고침/재접속하고 같은 테스트 브라우저에서 변경된 노드 좌표/설정/선이 유지됨을 확인.
12. **JSON 내보내기**: 변경된 워크플로 JSON 다운로드 가능 여부 확인.
13. **원본 복원**: '원본 복원'을 확인하고 GitHub 원본 워크플로 노드 구성이 복귀했는지 확인.
14. **운영 영향**: 원래 F01, F03, F05 GitHub JSON은 수정되지 않으며 외부 브로커 호출이 발생하지 않는다.

### 실패 시 보고

각 단계마다 '조작 요소', '실제 사용자 행동', '관찰된 UI/스크린샷', '성공/실패', '오류 메시지'를 기록한다.
브라우저에서 동작하지 않은 기능은 코드에 존재하더라도 성공이라고 하지 않는다.
복구되지 않은 기능은 수정 후 TinyFish로 재검사한다.

### 현재 저장 의미

'변경 저장'은 브라우저 localStorage에 초안을 저장하고 재접속 후 재로딩한다.
현재 방식은 네이티브 n8n 서버 DB에 저장하는 기능과 다르다.
실제 거래/서버 데이터베이스 저장 기능과 혼동하지 않는다.
